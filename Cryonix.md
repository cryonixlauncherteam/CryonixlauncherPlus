# ❄️ Cryonix Launcher Plus

**Cryonix Launcher Plus** is an advanced and customized Minecraft: Java Edition launcher for Android devices. Built upon the robust foundations of MojoLauncher and PojavLauncher, Cryonix Launcher Plus brings a unique visual identity, optimized performance, and a polished user experience tailored specifically for mobile gamers.

## ✨ Key Features

- **Minecraft: Java Edition on Android:** Play your favorite Java versions directly on your mobile device or tablet.
- **Instance & Version Management:** Easily manage multiple Minecraft versions, profiles, and game directories.
- **Mod Support:** Seamlessly install and run mod-loaders such as Fabric, Forge, and Quilt.
- **Custom UI & Animations:** Experience a clean, modernized interface featuring custom branding, smooth touch controls, and refined layout options.
- **Account Integration:** Support for both Microsoft accounts and offline/local profiles.
- **Optimized Runtimes:** Built-in multi-architecture Java Runtime Environment (JRE) support for enhanced compatibility and performance.

## 🚀 About the Project

Cryonix Launcher Plus aims to bridge the gap between desktop gaming and mobile convenience, providing a reliable, feature-rich environment for playing Minecraft Java Edition on the go. Whether you're exploring survival worlds with heavy optimization mods or playing vanilla with friends, Cryonix Launcher Plus gives you the tools to play your way.
